# TFT Archipelago

Downloads and automatic updates for **TFT Archipelago**, an [Archipelago](https://archipelago.gg) randomizer client for Teamfight Tactics.

You start a run with almost nothing unlocked: no shop rerolls, no XP buys, no augment rerolls, only the middle augment and three of five shop slots. Archipelago items unlock more over time. You complete checks by finishing Top 4 with certain board compositions.

TFT cannot be modded, so the app is an overlay. It places blockers over locked buttons and watches what happens in your match. Breaking a restriction invalidates the current match. The app never touches the game or its input.

## Download

Get `TFT-Archipelago-Setup-<version>.exe` from the [latest release](../../releases/latest).

## Install

1. Run the installer. It installs for your Windows user only and needs no admin rights.
2. The installer is not signed yet, so Windows SmartScreen may show "Windows protected your PC". Click **More info**, then **Run anyway**.
3. Start **TFT Archipelago** from the Start menu and follow the **Setup** page. It creates your player YAML and the APWorld for the multiworld host.

Requirements: Windows 10 or 11 (64-bit) and the Riot client with TFT.

## Updates

The app checks this page for new versions and downloads them in the background. A downloaded update installs when you close the app, or right away with **Restart** at the bottom of the sidebar. It never restarts while TFT is running.

## Uninstall

Uninstall **TFT Archipelago** in Windows Settings → Apps. Your settings in `Documents/TFTArchipelago` are kept.
